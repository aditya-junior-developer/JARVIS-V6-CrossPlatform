# JARVIS

Original MYRA desktop assistant being rebranded to JARVIS. The source archive has been recovered from the user's Part 1 and Part 2 ZIP files.

**Status:** The application source has not yet been uploaded to this repository. The provided archives are missing the actual React UI `src/main.tsx`; a separately supplied `src.zip` contains unrelated file-comparison library code. Do not assume this repo is currently buildable.

The local recovered source package excludes secrets, runtime/private data, dependencies and restricted model assets. Uploading those files without checking permissions or licensing is not recommended.
