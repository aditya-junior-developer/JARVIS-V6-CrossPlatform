JARVIS - RoL6mVzkCH PMX update

1. Copy your ORIGINAL RoL6mVzkCH.zip (not the preview image) to this folder. Rename that copy MY_MODEL.zip.
2. Run INSTALL_MY_MODEL.bat (requires Python 3).
3. Run START_JARVIS.bat, open http://localhost:3000
4. Hard-refresh with Ctrl+Shift+R.
